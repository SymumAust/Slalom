different model. All three methods compute the solution to the same Bellman equation:
J∗ = T J∗ (5)
Since every transition moves strictly from stage k to k+1 until the absorbing state ∆ is reached, this equation
is determined uniquely layer by layer, starting from the terminal condition J∗(N, ·) = gN . Consequently,
there is only one unique optimal value function.
• Backward Dynamic Programming (DP) solves the equation directly, processing one layer at a
time.
• Value Iteration (VI) reaches the solution by applying the Bellman operator T repeatedly. One
additional layer becomes exact with each sweep, meaning it becomes perfectly exact after 13 sweeps.
• Policy Iteration (PI) reaches the solution through a sequence of policies with non-increasing costs,
stopping when T Jµ = Jµ, which implies Jµ = J∗.
The agreement across all methods is exact (maximum difference of 0) because every successor state
lands precisely on an integer grid point, completely eliminating clipping or interpolation errors. The chosen
policies also match perfectly (0 disagreements) because all methods share the same tie-breaking rule: they
select the first control in the ordered sequence [−1, 0, 1] that falls within 10−12 of the minimum value.
Bellman Backup vs. Policy Evaluation
Both operations are constructed from the exact same fundamental quantity, ”cost now + expected cost-to-
go”:
Q(J, z, u) = g(e, eta, u) + sum(p * J[(k+1, e+eta-dr[k], eta+u+w)] for w, p in W)
Bellman Backup
Used in bellman T within VI, as well as the greedy step in DP, VI policy extraction, and PI improvement:
TJ[z] = min(Q(J, z, u) for u in admissible(eta))
This operator tests all admissible controls and retains the cheapest option, yielding the best achievable cost
starting from state z.
Policy Evaluation
Used in evaluate policy within PI:
J[z] = Q(J, z, mu[z])
This operator restricts itself strictly to the control prescribed by the current policy, yielding the total expected
cost of following that specific policy µ from state z.

Policy Iteration systematically alternates between these two operations: it evaluates the current policy,
then improves it by performing a greedy Bellman backup. In one line: the Bellman backup chooses the best
control, while policy evaluation follows a given control. Everything else in the table follows from that one
difference.
